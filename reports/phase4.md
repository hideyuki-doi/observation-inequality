## 1. 主解析（Tier B、10 グループ、M = 5×10⁻⁷〜3 g）

| 記録の種類 | β [95% CrI] | ベイズ R² | H1 | H2 |
|---|---|---|---|---|
| all | **0.72 [0.49, 0.94]** | 0.90 | 精度限定のスケーリング | 光学的予測（2/3）と区別できない |
| human_obs | 0.75 [0.48, 1.01] | 0.87 | 同上 | 同上 |
| specimen | 0.66 [0.38, 0.95] | 0.79 | 同上 | 同上 |
| dna | 0.51 [0.24, 0.79] | 0.72 | 同上 | 同上 |

* 収束：R-hat ≤ 1.01、bulk ESS ≥ 996、発散 0。
* **H1**：基準「幅 < 0.3」は満たさない（幅 0.45）。補助の基準「幅 < 0.6 かつ R² > 0.7」は満たす → **精度は限定的だがスケーリングはある**。
* **H2**：P(β − 2/3 > 0.2) = 0.09、P(β − 2/3 < −0.2) = 0.02 → **光学的予測と区別できない**。主の範囲（無脊椎動物と中深層魚）では、「人間の関心が主因」とは言えない。
* **H4**：P(b_dna < b_human_obs) = 0.935（差の中央値 −0.24）→ **支持**。

* 鳥類の傾きがほぼ 0 で τ が小さいのは、N 自体が eBird から推定されていることと整合する（循環）。予想どおりの結果で、解釈には使わない。

## 4. 解釈（暫定。人間の判断用）

1. **無脊椎動物と小型の海洋動物の範囲では、1 個体あたりの記録数は体重のおよそ 2/3〜3/4 乗でスケールしている**。光学的な予測と区別できない。
2. **脊椎動物（鳥類と哺乳類）は、その直線から大きく上に外れる**。ここに人間の関心による偏りが集中している可能性が高い。ただし、そのセンサスは主解析から外した種類（occurrence-derived と allometry-derived）なので、「外れの大きさ」には循環の問題が残る。
   * 報告ベースの哺乳類 388 種だけでグループの点を作れば、循環の少ない確認ができる（未実施。提案 1）。
3. **哺乳類の種間の傾き（0.32）は、分類群をまたぐ傾き（0.72）より緩い**。分類群間の差（大きな体サイズの差と、分類群ごとの関心の差）が、種内の差より強い構造を作っていると読める。
4. DNA 由来の記録は傾きが緩い（H4 支持）。ほとんどの感度分析で頑健だった。

## 5. 問題点

* 主解析の脊椎動物は中深層魚だけで、M の上限は 3 g。主の β は「微小〜小型動物の中の傾き」であって、全生命の傾きではない。
* S9 と S12 のような範囲の拡張で傾きが変わる → 単一のべき乗則では全体を表せない可能性がある（曲がっている、または分類群のまとまりごとに切片が違う）。PREREG にない探索的な解析（区分回帰、分類群の階層モデル）が必要なら、探索的と明記して行う。
* Phase 5 の H3 は「r(M) の事後分布」を使う。主の β（0.72）を使うと、脊椎動物の高い r を大きく過小に見積もることになる。Phase 5 に写す範囲は、主の M の範囲（5×10⁻⁷〜3 g）に限るのが PREREG に忠実。
* S3（individualCount 重み）は R² が 0.70 に下がり、H1 は不成立。プランクトンでの1記録＝多個体の扱いに敏感。
* NCBI は PREREG のとおり使っていない。S6 の寄生性線虫の除外と中深層魚の拡張科リスト、S15（未記載種の補正）は、出典が未確定なので未実施。
