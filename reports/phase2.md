# Phase 2 レポート：観測記録数の取得（2026-11-03）

## 1. やったこと

### 1.1 主解析用センサス表（Phase 1 ゲート判断の反映）

* `data/derived/census_main.csv` を作った。選択は `docs/census_main_selection.csv`、換算係数は `docs/conversion_factors.csv`。
* 内訳：
  * 主解析 10 グループ：土壌線虫、トビムシ、ダニ、アリ、ヒメミミズ類、カイアシ類、翼足類、クラゲ、中深層魚、ナンキョクオキアミ
  * 感度分析 3 行、DNA 解析専用 2 行（細菌、古細菌）
* 範囲合わせ（Bar-On の部分群）、ダニの派生値、換算係数は `docs/provenance_parts/harmonized.md` に記録した。
  * ダニの派生値は、Rosenberg のコードを乱数シードだけ固定して再実行し、公表値の合計を再現したうえで出した。
  * Rosenberg のコードは Python なので、スクラッチ領域に作った Python 環境で動かした（R と renv には触れていない）。
* 主解析の M（湿重量）は 4.8×10⁻⁷ g（土壌線虫）〜 3.1 g（中深層魚）で、約 7 桁にわたる。

### 1.2 GBIF

* SQL ダウンロードは使わず、**GBIF 公開スナップショット 2026-11-01**（AWS の Parquet、10,346 ファイル、総記録数 3.75×10⁹）を arrow で直接集計した。
  * 必要な列だけを読んだ。日本に近いシドニーのミラーも併用した。
  * ファイル単位の部分集計は `data/derived/gbif_agg/`、統合結果は `gbif_taxon_year.parquet` と `gbif_dataset_year.parquet`。
  * スクリプトは `scripts/phase2_launch.sh` と `scripts/phase2_worker.R`。
* occurrenceStatus = ABSENT は除外した。individualCount の件数と合計も保持している（感度分析用）。
* データセットの区分は API から取った（`data/raw/gbif_api/dataset_classes.csv`、91,008 データセット）。
  * DNA-derived data 拡張を持つデータセット、eBird、iNaturalist の研究グレードを区別した。
* グループと GBIF 分類群の対応規則は `docs/taxon_matching.md` と `docs/taxon_groups.csv`。
* **Tier A**：
  * Greenspoon の哺乳類（COMBINE の体重つき）と Callaghan の鳥類（AVONET の体重つき）を、GBIF の種名と照合した。
  * 完全一致しない種名は、GBIF v2 species match で COL XR の受理名に解決した（キャッシュは `name_match_cache.csv`）。

### 1.3 BOLD・NCBI

* BOLD 現行ポータル API（`/api/counts`、`/api/summary`）でグループ別の記録数と採集年月を取った（`data/derived/bold_ncbi_counts.csv`、`bold_by_year.csv`、取得日時つき）。
* NCBI nuccore は esearch で `txid[Organism:exp]` の件数を取った。

## 3. 問題点

1. **MATERIAL_SAMPLE ≠ DNA**。最初は MATERIAL_SAMPLE を DNA 由来としていたが、オキアミの記録の 87% がネット採集試料（KRILLBASE 系）だった。DNA の定義を「DNA-derived data 拡張を持つデータセットの記録」に改め、MATERIAL_SAMPLE は別区分にした。
   * ただし DNA の判定はデータセット単位。拡張つきの記録は 1.517×10⁸ 件、拡張つきデータセットの全記録は 1.56×10⁸ 件で、少しずれる。
2. **NCBI の件数はモデル生物に支配されている**（哺乳類 9,200 万件はヒト・マウスのゲノムなど、線虫 565 万件は C. elegans など）。体サイズとの関係を見る指標には使えない。代案：モデル生物を除く、または配列の数ではなく BioSample の数や種の数で数える。
3. **COL XR への移行**。スナップショットの分類体系が COL XR に変わっている。原核生物の界の名前は Pseudomonadati、Bacillati、Thermoproteati などになり、旧名（Bacteria/Archaea）では 0 件だった。同義語の解決は上記 2.3 のとおり。BOLD の原核生物は、新しい界の名前では 0 件だった（BOLD は旧名で 20,837 件を返す）。
4. **グループの対応づけの限界**。
   * 線虫：Nematoda 全体には海産・寄生性が含まれ、土壌線虫だけを分けられていない。
   * 中深層魚：ハダカイワシ科のみの仮置き。Irigoien 2014 が対象とした科のリストは未取得。
   * カイアシ類：淡水種や寄生性も含む。
   * 座標による陸と海の区別は集計に入れていない。
5. **オキアミ**：年増加率は −20% で、記録は過去に偏っている（2000–24 の割合は 14%）。ネット採集データセットが少数を占めている。
6. **主解析のグループの多くは不確実性がない**。Bar-On の部分群 5 つ（カイアシ類、ヒメミミズ類、翼足類、クラゲ、中深層魚）は、N にも B にも区間がない。Phase 3 で既定の不確実性を決める必要がある（例：Bar-On が動物に使った fold 10 を当てる）。
7. **Tier A の lump**：同じ受理名に複数種が落ちるケースが、哺乳類 89 種、鳥類 78 種ある。N を合算するか、除外するかを決める必要がある。
8. API で取ったデータセット別の総数（ファセット合計 3.89×10⁹）とスナップショットの総数（3.75×10⁹）は一致しない。取得時点の違いと考えられる。解析にはスナップショットの値を使う。
9. **引用**：スナップショットには DOI がない。論文の前に GBIF の derived dataset 登録で DOI を取る必要がある（データセットごとの件数は `gbif_dataset_year.parquet` から作れる）。
10. 記録数と個体数の比 r（R/N）は計算していない。Phase 3 の事前登録の前に結果を見ないためで、意図的に止めている。

## 4. 判断してほしいこと

1. DNA の定義：「DNA 拡張つきデータセット」を主にし、「MATERIAL_SAMPLE かつ拡張つき」を厳密版の感度分析にする（提案）。
2. NCBI：主解析には使わず、モデル生物を除いた件数を補助に回す（提案）。または完全に外す。
3. 不確実性のない主解析グループの既定値：Bar-On の動物一般の fold を当てる（提案）。具体値は Phase 3 の PREREG で決める。
4. Tier A の lump：合算して 1 点にする（提案）。
5. 線虫：Nematoda 全体を主にして（r を過大評価する方向）、寄生性の科を除いた版を感度分析にする。それとも座標を入れて集計し直すか（座標つきの再集計は約 2 時間かかる）。
6. 中深層魚の科リスト：Irigoien 2014 の本文から取る（次の作業として実施予定）。
7. 了承いただければ Phase 3（PREREG.md の作成）に進みます。

## 5. ゲート判断（2026-11-03、Doi：「全ておk」）

1. DNA は「DNA 拡張つきデータセットの記録」を主にする。「MATERIAL_SAMPLE かつ拡張つき」を厳密版の感度分析にする。
2. NCBI は主解析に使わない（モデル生物を除いた件数は補助のみ）。
3. 不確実性がないグループには既定の fold を当てる。値は PREREG で決める。
4. Tier A の lump は、N を合算して 1 点にする。
5. 線虫は Nematoda 全体を主にし、寄生性の科を除いた版を感度分析にする。座標つきの再集計はしない。
6. 中深層魚：Irigoien 2014 には科のリストがない（音響ターゲット強度の表はほぼハダカイワシ科のみ）。そのため主は Myctophidae のみ。拡張版の科リストは出典を確認してから感度分析にする。
