## 3. 問題点

1. **Bar-On の動物の N の多くは「B ÷ 仮定した1個体の質量」**（線虫 0.05 µg C、ヒメミミズ 25 µg C、カイアシ 4 µg C など）。観測記録に依存しないので循環論法ではないが、M = B/N は仮定値をそのまま返す。さらに N は B の部分範囲だけを指す（海産節足動物の N＝カイアシ類のみ、軟体動物＝翼足類のみ、刺胞動物＝クラゲのみ、魚類＝中深層魚のみ）。B と N の範囲をそろえ直す必要がある。また、この形では M の誤差がそのまま N の誤差になり、両者は相関する（Phase 4 の errors-in-variables モデルで扱う必要がある）。
2. **単位がばらばら**（Gt C、Mt 乾重、Mt 湿重）。Bar-On は動物に一律 C/湿重 = 0.15 を使っている。乾重→炭素、乾重→湿重の係数は、まだ出典付きで確定していない（推測では入れていない）。
3. **脊椎動物が薄い**：鳥類は独立データなし。魚の全体 N はない（Bianchi、Jennings、Hatton の魚は体サイズスペクトル理論のモデル = allometry-derived で、Hatton と Bianchi は産業化以前の値）。両生類・爬虫類・淡水魚の全球推定は見つからなかった。
4. **未確認**：
   * ダニの全球 N と B（Rosenberg は割合だけ。Zenodo のコードを回せば出せる）
   * ミミズの全球合計（Phillips 2019 本文は単位面積あたりの値だけ。補足資料は入手できず）
   * 線虫の「± 0.64」の意味（Nature 本文は有料で、HAL と ETH GitLab はボット対策で取得不可）
   * Bar-On の微生物・植物・ウイルスのノートブックは未監査（unclear のまま）
   * Wilson et al. 2009（魚類、science.org 403）
   * BirdLife/IUCN の種別個体数（Data Zone への申請か API トークンが必要）
   * Greenspoon 2023 への PNAS レターは未読
   * 次は全球推定が見つからなかった：カイアシ類単独、魚の個体数、頭足類、海産線虫・メイオファウナ、サンゴ、淡水魚、両生類、その他のオキアミ類
5. **記載種数**の多くはまだ空欄（Bar-On の図シートの種数は出典がない）。Catalogue of Life などから一貫して取る必要がある。
6. Greenspoon のデータの細かい点：報告種 + 予測種 = 4,806 種で、表の行数 4,795 と 11 合わない。2025 年版の歴史データには入力ミスと思われる行がある（キタシロサイとミナミシロサイの現存数が入れ替わっている、*Capreolus capreolus* が "Red kangaroo" と表記されている）。2025 年版の海生の区間は「95%CI」と書かれているが、5〜95 パーセンタイルから作っているので、ここでは CI90 として記録した。
7. GBIF SQL ダウンロードの権限は未確認。申請に時間がかかる可能性があるので、Phase 2 の前に申請を出しておくのがよさそうです。

## 4. 判断してほしいこと

1. **鳥類の扱い**：Callaghan は occurrence-derived とし、主解析から外して感度分析だけで使う（提案）。独立した代替として BirdLife/IUCN の個体数推定を申請するかどうか。
2. **哺乳類**：主解析の Tier A を、報告ベースの 392 種（＋海生）に限ってよいか。ただし IUCN の値も「密度 × 分布域」の専門家推定を含むので、私はこれを unclear と見ています。それとも Tier A は全体を感度分析に回し、主結果は Tier B に寄せるか。
3. **Bar-On の「B ÷ 仮定質量」で作った N**：主解析に入れてよいか（N は独立だが、M は仮定値）。入れる場合は、B を N と同じ範囲（カイアシ類だけ、など）にそろえ直す（提案）。
4. **重複する推定の主値**：
   * トビムシ：Rosenberg（3×10^18）か Potapov（2×10^18、B あり）か。提案は Potapov を主にし、Rosenberg を感度分析に回す。
   * アリ：Schultheiss 全体（mixed）か Rosenberg の非樹上性アリか。
   * 中深層魚：Irigoien か Proud か。
5. **自分たちで計算する値**（派生値と明記したうえで）：
   * ダニの N と B を Rosenberg のコードから出すか。
   * ミミズの全球合計を Phillips の地図から出すか。
6. **微生物（原核生物、Prochlorococcus）を回帰に入れるか**：GBIF 上の記録はほぼすべて配列由来なので、H4（DNA 記録の傾き）向きです。人による観察記録の回帰では、M の範囲を広げる代わりに性質の違う点を足すことになります。
7. **単位換算の方針**：湿重量に統一し、Bar-On の 0.15（C/湿重）を基準にする。乾重の換算は文献を探して出典付きで決める。
8. **産業化以前の値**（Hatton の魚、Bianchi）：現在のセンサスからは外す（提案）。

承認いただいたら、census.csv を主解析用に絞り込んだ版（`census_main.csv`）を作ってから Phase 2 に進みます。

## 5. ゲート判断（2026-11-03、Doi：「全部提案の通りでいい」）

提案を出していた項目はその通りにする。選択肢だけを示していた項目は、下の既定値で進める（変更する場合は追記）。

1. Callaghan 2021：主解析から外し、感度分析だけで使う。BirdLife/IUCN データの申請は保留。
2. 哺乳類 Tier A：主解析は個体数報告に基づく 392 種（＋海生）。全 4,795 種は感度分析。主結果は Tier B に寄せる。
3. Bar-On の「B ÷ 仮定質量」で作った N：主解析に入れる。B を N と同じ範囲にそろえ直す。M の誤差と N の誤差の相関は Phase 4 のモデルで扱う。
4. 主値：
   * トビムシ：Potapov。Rosenberg は感度分析。
   * アリ：Rosenberg の非樹上性アリ（independent）。Schultheiss は mixed なので感度分析。
   * 中深層魚：Irigoien。Proud は感度分析。
5. ダニ：Rosenberg のコードから計算し、派生値と明記する。ミミズ：Phillips 2019 の補足資料が取れれば地図から合計し、取れなければ「全球値なし」とする。
6. 微生物：H4（DNA 由来記録）の解析に入れる。人の観察記録の主回帰には入れず、感度分析とする。
7. 単位：湿重量に統一する。動物は Bar-On の C/湿重 = 0.15 を使う。乾重の換算係数は出典付きで決める。
8. 産業化以前の推定値（Hatton の魚、Bianchi）：除外する。

GBIF：SQL ダウンロードの代わりに、GBIF 公開スナップショット（AWS の Parquet、2026-11-01 版、10,346 ファイル）を arrow で読むことを提案（匿名アクセスを確認済み）。引用は GBIF の derived dataset 登録で DOI を取る。
